# 账号美元额度

账户卡片显示两项（USD）：

- **已跑额度（累计）**：功能开始追踪后，网关最终向下游交付的用量，按该下游模型的官方标准 API 价格折算。不是 Kiro 采购成本。历史账号的旧 `TotalTokens` 缺少模型、缓存类型和膨胀信息，不据此伪造历史美元值。
- **预估额度（本周期）**：通过本账号在有效积分周期内的连续样本估计“整个积分额度可以跑出多少官方 API 等价美元”。不是剩余美元余额，也不是固定套餐售价。

## 模型与缓存定价

价格目录位于 `costledger/catalog.go`，核验日期 2026-10-19，来源为 [Anthropic 官方价格表](https://platform.claude.com/docs/en/about-claude/pricing)。每个模型分别定价，普通输入、输出、缓存读取、5 分钟缓存写入、1 小时缓存写入互斥计数。自建缓存使用最终下游 usage 对应的读写价格。用量在 context 修正、重试映射、token 膨胀及上限处理后记一次；不再重复膨胀，不把 reasoning 当成另一份输出。价格分档基于完整请求长度，而不是跨账号分摊后的片段长度。

明确的项目模型别名解析后才查目录；未知型号会记录为待定价，不当成零费用。金额不包含工具调用独立费用、税费、折扣、Fast/Batch/地区特殊附加费。

## 加权估算

直接采集 AWS getUsageLimits 的绝对积分快照，优先 CREDIT 资源，兼容 AGENTIC_REQUEST；使用 precision 字段，包含有效基础、试用和奖励积分桶。不使用本网关累计 `TotalCredits` 代替上游余额。

对两个采样点之间的不重叠区间：

```
区间积分比例 = (本次已用积分 - 上次已用积分) / 本周期总积分
区间总额度估值 = 区间已跑美元 / 区间积分比例
权重 = 时间衰减权重 × 区间积分比例
最终预估 = Σ(权重 × 区间总额度估值) / Σ权重
```

默认时间半衰期 60 分钟，区间内部按均匀消耗近似衰减；最短 60 秒，积分差分至少 `max(0.1, 总积分×0.0001)`。小幅/零变化不前移锚点，继续累积，避免把 AWS 更新延迟放大成离谱估值。最近样本超过 6 小时则显示过期。积分重置、任一桶用量回退、额度/有效桶集合/有效期变化均重新采样，不沿用旧比率；累计已跑美元仍保留。

启动后建立新鲜积分锚点；活跃账号每分钟采样，最多 4 个并发、单次 20 秒，可取消。15 分钟没有下游活动则暂停频繁采样。采样不阻塞推理请求，不改变账号启用/封禁状态。共用账号在其他客户端消耗积分或上游延迟更新都会影响估算精度。

## 交付和持久化

一个下游逻辑请求只结算一次；内部失败尝试不单独记美元。隐藏重试、多轮工具/advisor/code execution 用量按来源账号归属，保留最终用量总数；不把多个账号的用量全部记到最后一个账号。只有完整交付的终态 usage 才记完整金额；真正的部分内容交付而缺终态用量会标记累计不完整，纯错误响应不虚构 token 费用。网络层“交付”表示本服务成功写出并 flush，不代表远端应用已消费或持久化。

账本文件与配置同目录：`account_quota_ledger.json`。请求只更新内存；后台约 2 秒合并写入，私有 0600 临时文件同步后原子替换（Linux 同步目录），写失败会自动重试，正常关闭时 flush。该文件仅含账号 ID、金额、积分快照与去重状态，不保存请求正文和凭据。损坏文件不会被清零覆盖；页面显示记录异常。回滚二进制不回滚账号配置或美元账本。
