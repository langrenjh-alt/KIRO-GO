# 独立代理池

代理池在本项目自身的 `config.json` 中保存代理与账号绑定，不再读取其他项目的代理来源、租约或文件。管理后台左侧的 **代理池** 页面用于导入、巡检和批量维护。

## 开关与分配规则

- **设置 → 代理池** 与 **代理池 → 启用账号代理池** 是同一个后端字段 `proxyPoolSettings.enabled`。任何一处修改后，两处显示同一个状态。
- 新配置默认关闭账号代理池；“无可用代理时阻断账号”默认开启。旧配置若开启了临时绑定功能，只迁移其开启状态，不迁移旧来源的代理或租约，因此应先导入可用代理。
- 代理池开启后，所有启用且未被封禁、禁用或挂起的账号均按同一规则绑定，包含 Free、Pro、Pro+、Power、Max 及自定义等级。
- 系统保留有效绑定；为未绑定账号分配时优先使用零绑定代理，之后选择绑定数量最少的代理。允许多个账号共享同一代理；绑定不会定时过期。
- 新增、批量导入、重新启用账号会立即参与分配。封禁、禁用、挂起或删除账号会立即解除绑定。
- 关闭账号代理池会解除池内绑定，恢复原有的账号单独代理／全局代理行为；代理记录和累计流量保留。
- **无可用代理时阻断账号** 是独立开关，仅在账号代理池开启时生效。开启时，无绑定可用代理的账号不会被调度，也不会发出直接请求；关闭时，此类账号允许直接连接，不使用旧的账号／全局／环境代理作为替代。

## 导入与维护

代理导入框每行一条，支持完整 HTTP、SOCKS5 地址，也支持按所选协议补全 `host:port`。例如：

```text
http://proxy-a.example:8080
socks5://proxy-b.example:1080
proxy-c.example:8080
```

重复代理地址会跳过；导入结果会分别显示新增数、重复数与错误行。单次最多导入 10,000 条。新增代理默认启用，健康状态在首次检测前显示为“未检测”。

列表支持搜索、状态筛选、多选，以及批量编辑名称／连接信息、检测、启用、禁用、删除。批量编辑在全部目标通过校验后一次保存；失败时不会留下部分修改。修改代理地址后，旧地址的进行中检测结果不会覆盖新地址。

列表默认每页 **20 条**，可选择每页 10／20／50／100 条，浏览器会记住每页条数。页面底部提供首页、上一页、下一页、末页和页码跳转，并显示筛选结果总数、当前显示范围及总页数。搜索、状态筛选或每页条数改变时回到第一页；自动刷新、切换页面和语言保留当前页。删除或巡检状态变化导致页数缩减时，会自动定位到最后一个有效页。

**全选当前页** 仅选择或取消当前页的代理，不影响其他页的已选代理。选择会跨页保留，工具栏同时显示跨页已选总数和当前页已选数；可点击 **清空选择** 一次取消全部选择。批量操作作用于跨页选择的全部代理。上方汇总指标始终统计整个代理池，**全部检测** 仍检测整个代理池，不受分页、搜索、筛选影响。

手动禁用和巡检禁用的代理都不会被后续检测自动重新启用。手动检测恢复健康后，管理员可以确认结果并点击启用。

## 自动巡检与故障切换

- 默认每 **60 秒** 发起一轮，默认 **16 个并发工作线程**。管理接口可调整为 10–3,600 秒、1–64 个并发。
- 巡检在后台执行，不阻塞账号请求；上一轮未结束时不会叠加新一轮。单条检测具有超时，支持服务关闭时取消。
- 检测包括连通性、延迟、出口 IP、国家、地区与城市。地理查询异常不等同于代理断网：连通性与出口 IP 已确认时仍显示健康，并保留地理信息待补充的提示。
- 巡检确认网络不可用后立即禁用该代理，并为受影响账号重新分配其他启用且非故障的代理。
- 账号运行中的代理连接错误同样触发禁用与重绑定。请求只有在尚未开始返回响应且请求体可重建时才会尝试其他代理；已开始输出的流不会被重放。
- 无可用替代时，系统遵守“无可用代理时阻断账号”开关。正常的上游 HTTP 401／403／429／500 响应不应当被当成代理断网；调用方取消也不会禁用代理。

账号请求的推理、REST 查询、模型／用量／配置查询、令牌刷新和账号关联工具请求都在实际发出请求时重新解析绑定。已经缓存的 HTTP 客户端不会固化旧代理。

## 指标口径

| 列 | 含义 |
| --- | --- |
| 绑定账号数 | 当前持久化绑定到该代理的有效账号数量，不是历史分配次数。 |
| 当前并发 | 正在使用该代理、尚未读完或关闭响应体的项目出站请求数，包括流式请求。 |
| 当前流量 | 最近 5 秒应用层请求体与响应体字节的平均速率，单位 B/s。 |
| 总流量 | 应用层累计请求体与响应体字节；后台批量落盘，重启后保留已保存部分。 |

流量不包含 HTTP 头部、TCP、TLS 等协议开销，也不是整台服务器或代理供应商计费流量。后台约每 5 秒持久化增量，正常关闭时也会刷新；突然断电可能丢失最后尚未落盘的一小段流量。

## 管理接口

所有路径都位于现有管理接口下，沿用管理后台的会话校验。

| 方法与路径 | 请求与结果 |
| --- | --- |
| `GET /admin/api/proxy-pool` | 返回 `settings`、`proxies` 和 `inspection`。 |
| `POST /admin/api/proxy-pool/settings` | 局部更新 `enabled`、`blockWithoutProxy`、`checkIntervalSeconds`、`checkConcurrency`。 |
| `POST /admin/api/proxy-pool/import` | `{"text":"http://proxy.example:8080\nsocks5://proxy.example:1080","defaultScheme":"http"}`。 |
| `POST /admin/api/proxy-pool/check` | `{"ids":["PROXY_ID"]}`；异步检测，返回 HTTP 202。 |
| `POST /admin/api/proxy-pool/batch` | `{"action":"enable","ids":["PROXY_ID"]}`；操作支持 `check`、`enable`、`disable`、`delete`、`edit`。 |

设置示例：

```json
{
  "enabled": true,
  "blockWithoutProxy": true,
  "checkIntervalSeconds": 60,
  "checkConcurrency": 16
}
```

批量编辑示例：

```json
{
  "action": "edit",
  "ids": ["PROXY_ID_A", "PROXY_ID_B"],
  "patch": {"name": "备用代理", "scheme": "socks5"}
}
```

## 验证与回退

开发验证使用真实项目包，不扫描 `exports/` 中的历史临时 Go 文件：

```bash
go test ./config ./pool ./auth ./egress ./proxy ./logger ./web .
go vet ./config ./pool ./auth ./egress ./proxy ./logger ./web .
go build -o kiro-go .
```

支持 CGO 的 Linux 构建环境可额外执行：

```bash
CGO_ENABLED=1 go test -race ./config ./pool ./auth ./egress ./proxy
```

日常停用代理池只需关闭共享开关。版本回退应使用对应部署备份中的程序和配置，保留当前配置副本，避免用旧版本覆盖新保存的代理池配置。
